Cinderella

A girl dreams of a different life.

Cinderella lives with her stepmother and two stepsisters. They make her do all the housework.

One evening, everyone is invited to a royal ball. Cinderella wants to go, but her stepmother refuses.

A fairy godmother helps her. At the ball, Cinderella meets the prince.

If I were Cinderella, I would stand up for myself.

If I had a magic wand, I could change my life.

🧠 Step 2. Grammar Lab

가정법 과거는 현재 사실과 반대되거나 실현 가능성이 낮은 상황을 상상할 때 사용합니다.

IF CLAUSE

If + 주어 + 동사의 과거형

만약 ~라면
MAIN CLAUSE

주어 + would/could/might + 동사원형

~할 텐데
If I were Cinderella, I would leave the house.

내가 신데렐라라면, 그 집을 떠날 텐데.

Rule 1. If절에는 과거형

If I had a magic wand, I would help others.
If I knew the truth, I would tell her.

Rule 2. would + 동사원형

✓ I would go home.
✗ I would went home.
✗ I would gone home.

Rule 3. If I were ...

학교 문법에서는 가정법 과거의 be동사로 주어에 관계없이 were를 사용하는 형태를 기본으로 학습합니다.

Rule 4. would / could / might

would — ~할 텐데
could — ~할 수 있을 텐데
might — ~할지도 모르는데

Rule 5. 동사의 형태 비교

원형과거형과거분사
gowentgone
seesawseen
knowknewknown
givegavegiven
bewas/werebeen
이미 일어난 과거 사건을 바꾸어 상상할 때는 가정법 과거완료를 사용합니다. 이번 활동은 현재 인물의 역할을 맡는 상황을 중심으로 연습합니다.
